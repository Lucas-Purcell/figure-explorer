# Change Log

All notable changes to the "figure-explorer" extension will be documented in this file.

## [0.1.12] - 2026-08-12
### Improved
- Fixed zooming of the preview image when in the sidebar.
- Added copy image function when right clicking figure previews.
- Added save image function when right clicking figure previews.
- Added export pdf function when right clicking figure previews.
- Added multi-selection of items in the gallery view.
- Modified comparison mode interaction. Allowed zooming.
- Added exporting features.
- Added copy image function.


## [0.1.11] - 2026-08-12
### Improved
- Added the ability to zoom in on the preview image.

### Removed
- Made log messages only visible in debug mode.
